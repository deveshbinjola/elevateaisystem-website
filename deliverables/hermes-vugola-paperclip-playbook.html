3Exact Steps · Path A (Coach Platform Module)

This is the 7-step buildout to ship the Clip Engine module inside the existing Coach Platform stack.

1

Wire Vugola into coach-app via MCP

Vugola already exposes a Claude-compatible MCP. Add it as a connector inside the coach-app Supabase edge function. New env var: VUGOLA_API_KEY. New Supabase table: cp_clip_jobs (coach_id, source_url, status, clip_count, created_at).

2

Source input: RSS or upload

Coach pastes podcast RSS or YouTube URL in onboarding. Background job pulls newest episode every 24h. Store transcript in cp_clip_sources.

3

Vugola produces 8-12 clip candidates per hour of source

Call Vugola with the source URL. It returns clip start/end timestamps, virality score, a draft caption, and a draft hook. Store in cp_clip_candidates.

4

Voice Mapping rewrites every caption (this is the wedge)

For each candidate, call the existing Voice Mapping pipeline with the draft caption. Output a 3-variant caption set (LinkedIn long, IG short, X punchy) all in the coach's voice. Branch by audience signal (male / female) per the female-voice adaptation work in flight.

5

Swipe-to-approve UI

One screen, one clip at a time. Approve, edit caption, or skip. Mobile-first. Follow Lex's feedback: open one surface tied to stated pain, do not show settings unless asked.

6

Auto-schedule to LinkedIn / IG / TikTok / X

Use Buffer or Postiz API behind the scenes. Coach never sees Buffer. Brand promise: "you approve, we post." Default cadence: 3-5 clips per week per platform.

7

Weekly conversion report

Tie clip views to DMs received, profile visits, Cal.com bookings, and Coach Platform signups (UTM attribution). Email digest every Monday at 7am via Paperclip. This is the "content → conversion" proof the platform sells on.
